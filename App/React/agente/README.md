# Nakomi - Centro de Planificación

Este directorio contiene los roadmaps por fase del proyecto Nakomi.

## Estructura de Fases

| Fase | Nombre              | Estado        | Descripción                         |
| ---- | ------------------- | ------------- | ----------------------------------- |
| 1    | Landing MVP         | 🔄 En progreso | Landing minimalista + portafolio    |
| 2    | Panel Cliente       | ⏳ Pendiente   | Layout panel + servicios en proceso |
| 3    | Contratación        | ⏳ Pendiente   | Catálogo + flujo de compra          |
| 4    | Suscripciones       | ⏳ Pendiente   | Planes + facturación                |
| 5    | Panel Admin         | ⏳ Pendiente   | Gestión clientes/empleados          |
| 6    | Servicios Avanzados | ⏳ Pendiente   | Hosting, acciones complejas         |

## Convenciones

- Cada fase tiene su propio archivo `fase-N.md`
- Las tareas se marcan con: `[ ]` pendiente, `[x]` completado
- Se actualiza progresivamente según avanzamos
