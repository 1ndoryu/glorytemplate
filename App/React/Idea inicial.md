# Proyecto Nakomi - Contexto General

## Qué es Nakomi

Plataforma de servicios freelance similar a Fiverr, con:

- **Landing ultra minimalista** con portafolio de proyectos
- **Panel de clientes** para gestionar servicios y suscripciones
- **Marketplace** de servicios con contratación, pagos y reseñas
- **Panel admin** para gestión empresarial

## Servicios Ofrecidos

- Aplicaciones React
- Apps móviles
- Temas WordPress desde cero
- Mantenimiento WordPress
- Sitios con Laravel
- Sitios en frameworks populares
- Aplicaciones Windows (JS)
- Ciberseguridad para apps
- Hosting y dominios

## Visión del Diseño

- **Extremadamente minimalista**
- Logo "nakomi" como texto que cubre ancho completo dinámicamente
- Grid de proyectos debajo
- Tipografía pequeña, todo compacto
- Paleta oscura (#090909 base)

## Usuarios del Sistema

| Rol          | Descripción                                             |
| ------------ | ------------------------------------------------------- |
| **Cliente**  | Contrata servicios, gestiona suscripciones, se comunica |
| **Empleado** | Atiende servicios asignados, entrega trabajos           |
| **Admin**    | Gestiona ingresos, clientes, facturación, asignaciones  |

## Notas Técnicas

- Backend: WordPress (para agilizar gestión de usuarios y contenido)
- Frontend: React Islands (Glory framework)
- Variables CSS: prefijo `--nakomi-*`
- Hosting propio: Coolify (sin cPanel)
