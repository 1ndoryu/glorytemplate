## 183A-43 — Stack completo de push notifications Android (causa raíz)
- **Que:** Las notificaciones push no funcionaban por CUATRO causas acumuladas: (1) Variable `KAMPLES_FCM_SERVICE_ACCOUNT_JSON` no existía en el servidor — sin ella, `ServicioFcm` aborta silenciosamente. Se corrigió a `UsuarioHelper::obtenerPorWpId()`.
- **Archivos:** App/Kamples/Api/Controladores/FcmController.php (fix método inexistente), App/Kamples/Services/ServicioFcm.php (log warning), App/React/services/fcmToken.ts (debug temporal agregado y removido), servidor (.env Coolify + tabla fcm_tokens)
- **Gotchas:** (a) Logger en producción tiene `nivel: NivelLog.ERROR` (valor 0) — `log.info()` y `log.warn()` están completamente silenciados, haciendo invisible el debug de FCM. Se usó `console.error` temporal para diagnosticar. (b) Capacitor carga JS desde `server.url: "https://kamples.com"`, no del APK local — los cambios JS deben desplegarse al servidor para que el emulador los vea. (c) `sessionStorage['fcm_token_registrado']` puede quedar pegado en "1" de una sesión fallida previa, impidiendo re-registro. Se limpió via Chrome DevTools Protocol.
- **Verificado:** Token `eE4t-DOZQ0GeOgo2WjwK...` registrado para usuario PG id=4 en PostgreSQL. Push enviado desde servidor → `pushNotificationReceived` en logcat → `NotificationManagerService` procesó notificación → visible en bandeja Android canal "notificaciones".
